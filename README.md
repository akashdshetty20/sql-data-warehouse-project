# sql-data-warehouse-project
Building a modern Data Warehouse with sql server.

This project implements a modern SQL Data Warehouse from scratch using SQL Server.
It covers the end-to-end ETL process, including data ingestion from CRM and ERP systems.
The architecture follows a structured Bronze, Silver, and Gold layer approach for robust data processing.
Key steps include data modeling using the Star Schema and establishing comprehensive data lineage.
The repository includes full DDL scripts, stored procedures, and quality checks for production-ready analytics.
